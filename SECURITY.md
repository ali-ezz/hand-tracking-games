# Security Policy

## Reporting a vulnerability

If you find a security issue, please do not open a public issue.

Instead, use the GitHub security advisory process for this repository:

https://github.com/ali-ezz/hand-tracking-games/security/advisories

If that option is not available, contact the repository maintainers directly and mark the report as security-sensitive.

## Response

Maintainers aim to acknowledge valid reports within 7 days and provide an update as soon as possible.

## Supported vulnerability reports

- Cross-site scripting (XSS)
- Data exposure through `localStorage`
- Camera or permission handling problems
- Third-party library security issues
